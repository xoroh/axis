# Support

Axis released its first version (0.1.0) in October 2026. For usage questions and reproducible bugs, [open an issue](https://github.com/xoroh/axis/issues) and include your OS/React Native versions, the package version, steps to reproduce, and expected versus actual behavior.

For feature proposals, use the feature-request issue template. For security vulnerabilities, do not open a public issue; follow [SECURITY.md](SECURITY.md).
