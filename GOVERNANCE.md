# Governance

Axis is maintained by the [Xoroh organization](https://github.com/xoroh). Issues and pull requests are the public record for proposals, implementation discussion, and project decisions.

For substantial changes, open an issue before implementation. Maintainers review contributions for project fit, correctness, security, and compatibility with the MIT License. Pull requests should target `development`; maintainers decide when changes are ready for release.

As the project grows, this document will be updated with maintainer roles and more detailed decision and release procedures.
