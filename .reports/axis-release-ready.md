## 3. Release-day checklist (for the authorized run)

1. Owner authorizes: set `RELEASE_CHANGESSETS='true'`, approve
   the `npm-publish` environment, dispatch `Release` workflow on GitHub Actions.
2. `changesets/action` consumes `.changeset/*.md`, updates `packages/axis/package.json`
   from `0.0.0` to `0.1.0`, generates `packages/axis/CHANGELOG.md`, tags `axis-v0.1.0`,
   and publishes `@xoroh/axis@0.1.0` to npm with provenance.
3. After the Axis publish: Kern swaps its vendored `file:` spec
   to the semver range `^0.1.0`.
4. Never publish from a laptop (`npm publish` by hand bypasses
   the provenance and environment gates).
